# Replace-Solo 機能仕様書 (docs/spec.md)

## 1. プロジェクト概要

- **名称**: Replace-Solo（リプレイス・ソロ）
- **サブタイトル**: 〜ブラウザ内で処理が完結するMicrosoft Loop専用の置換ツール〜
- **目的**: Microsoft Loop上で、議事録等の固有名詞や特定の口癖を抽出し、一括置換する。

## 2. 主要機能

### A. 解析・抽出 (Extraction)

- **トリガー**: サイドパネル上の「対象抽出」ボタン押下。
- **対象**: アクティブなタブのページ全体。
- **ロジック**: `kuromoji.js` を使用し、名詞（特に固有名詞）を中心に抽出。
- **リスト表示**: 重複する単語は1行に集約。

### B. 置換エンジン (Replacement)

- **置換方法**: `document.execCommand('insertText')` (入力エミュレーション) を使用。リッチエディタの履歴やカーソル位置を維持しながら安全に置換を行う。

### C. 辞書データ管理 (Dictionary)

- **構造**: `{"置換文字列": ["元単語1", "元単語2", ...]}` (1:N 形式)
- **永続化**: `chrome.storage.local` を使用。
- **インポート/エクスポート**: JSON形式。上書き/追加を選択可能。スキーマバリデーションを実装。

### D. ページ内パネル (PWA ウィンドウ対応)

- **背景**: Chrome のサイドパネルは通常のブラウザウィンドウにしか存在せず、Loop を PWA（アプリ）ウィンドウで開いた場合は表示できない。そのため、ページ内に UI を描画する代替手段を提供する。
- **表示**: 対象ページ（`/p/` で始まるページ）でのみ、画面右下にフローティングボタンを表示。クリックまたは `Alt+Shift+R` でパネル（約360px、Shadow DOM で描画しページ側のスタイルと分離）を開閉する。
- **機能**: サイドパネル版と同等の「対象抽出」「手動追加」「一括置換」「単体置換」「辞書登録」を提供する。抽出・置換は `content.js` の関数を、辞書は `chrome.storage.local` の `dictionary` キーをサイドパネル版と共用する（パネルを開くたびに辞書を読み直すため、相互の変更が反映される）。
- **実装**: `manifest.json` の `content_scripts` で `lib/kuromoji/kuromoji.js` → `scripts/content.js` → `scripts/inpage.js` の順に対象ドメインへ読み込む（`document_idle`）。Loop は SPA のため、URL の変化を1秒間隔で確認し、対象ページかどうかでボタンの表示を切り替える。

### E. 検索と置換モード (ページ内パネル)

- **背景**: 辞書置換は「抽出された対象」を置き換える機能であり、任意の文字列をその場で探して直す用途には向かない。VS Code の検索ウィジェットに相当する操作をページ内パネルに追加する（サイドパネル版には未搭載）。
- **モード切替**: パネル上部の切替で「辞書置換」と「検索と置換」を切り替える。辞書モードへ戻る、またはパネルを閉じると検索ハイライトは消去される。
- **検索**: 検索語を入力すると（200ms のデバウンス後）ページ内の編集可能なテキストから一致を集め、全一致をハイライト（現在位置は別色）し、「現在位置 / 件数」を表示する。Enter で次へ、Shift+Enter で前へ移動し（循環）、移動先へスクロールする。スクロールは段落要素ではなく一致箇所（Range）の矩形を基準に量を決め、スクロール後に可視領域へ入ったかを確認し、外れていれば一度だけ補正する（エディタ側のスクロール管理と競合して途中で止まるのを防ぐため）。オプションは「大文字と小文字を区別 (Aa)」と「正規表現 (.*)」で、正規表現が不正な場合はその旨を表示する。
- **置換**: 通常は検索のみで、展開ボタン（›）を押したときだけ置換欄が開く。置換欄からは現在の一致1件の置換と、全一致の一括置換ができる。
- **制約**: 置換できる一致は辞書置換と同じく「同一コンテナ（段落等）内に収まる一致」に限る。段落を跨ぐ一致は対象にしない。置換は辞書置換と同じ入力エミュレーションを使うため、Loop の Undo（Ctrl+Z）で戻せる。
- **不可視の文字列**: `display:none` / `visibility:hidden` / `content-visibility:hidden` の配下にある文字列は、画面に見えていないため検索の対象にしない。この除外はノード判定（`isSafeTextNode`）を共用する辞書の抽出・置換にも効く。なお、画面外への配置（position で飛ばした要素）や読み上げ専用テキストは判定対象外。
- **ドキュメント変更への追従**: 検索語がある間は対象ルートを `MutationObserver` で監視し、置換後の Undo や本文の手動編集で一致が変わったら、再検索して件数表示とハイライトを実態に合わせる（現在位置は可能な範囲で維持）。検索を消去（モード切替・パネルを閉じる・検索語を空にする）すると監視も止まる。

## 3. UI詳細 (サイドパネル)

### 抽出リスト・操作テーブル

| 要素       | 種別                          | 動的挙動                                                          |
| :--------- | :---------------------------- | :---------------------------------------------------------------- |
| 選択       | M3 Checkbox                   | 初期値：辞書マッチならON、なければOFF。置換文字列の入力で自動ON。 |
| 対象       | Body Large                    | 抽出された単語。                                                  |
| 置換文字列 | M3 Filled Text Field / Select | 辞書から自動展開（プルダウン選択可能）。                          |
| 辞書登録   | M3 Checkbox                   | 置換時に保存するか。                                              |
| 単体置換   | M3 IconButton                 | その行のみ即座に置換。                                            |

### 操作エリア

- **手動追加**: 対象をリストに直接追加。
- **一括置換**: 「選択」がONの項目を全置換。
- **リセット**: 抽出直後の状態に戻す。

## 4. 権限 (Permissions)

- `sidePanel`: サイドパネルの利用。
- `storage`: 辞書データの保存。
- `scripting`: ページ内での置換実行。
- `activeTab`: 現在のタブへのアクセス。

## 5. 対象ドメイン (自動判定)

- `loop.microsoft.com`
- `loop.cloud.microsoft`
